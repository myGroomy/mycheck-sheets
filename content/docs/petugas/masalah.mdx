# Pemecahan Masalah

Gunakan tabel ini untuk pemeriksaan awal sebelum menghubungi admin. **Jangan
pernah menyalin PIN atau token ke pesan siapa pun.**

| Gejala | Pemeriksaan |
| --- | --- |
| Tidak bisa login | Periksa username dan PIN, pastikan aku tidak dikunci. Bila PIN lupa, minta admin reset PIN. |
| Kembali ke halaman login terus | Login ulang. Cek waktu perangkat tidak jauh melenceng dan cookie browser diizinkan. |
| Data shift tidak muncul | Pastikan cabang kerja kamu benar. Periksa koneksi, refresh sekali, lalu buka lagi. |
| Gabungan shift gagal | Periksa koneksi, pastikan kamu belum tergabung ke shift yang sama. |
| Checklist/handover gagal disimpan | Periksa jaringan, muat ulang status sebelum mengulangi aksi. Jangan kirim berulang-ulang tanpa memastikan hasil. |
| Foto tidak tampil | Periksa koneksi, buka ulang halaman. Bila kasus sering terjadi, laporkan ke admin untuk cek akses. |
| Tindak lanjut incident? | Ditindaklanjuti admin — cek di daftar incident untuk update. |

## Lapor masalah dengan benar

Sertakan: waktu kejadian, langkah yang mengulang persoalan, pesan error (lewat
foto tanpa data sensitif), dan jenis perangkat/browser. Jangan simpan data
personal (PIN, cookie, token berbagi) ke dalam laporan.

Untuk masalah data, **jangan mengedit atau menghapus baris spreadsheet secara
manual** — laporkan ke admin supaya ditindak melalui aplikasi dan audit log.
