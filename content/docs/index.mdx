# Dokumentasi MyCheck

Panduan praktis untuk tim outlet dan admin yang menjalankan operasional shift
berbasis checklist. Mulai dari login, buka shift, simpan draft, sampai laporan
siap ditinjau.

<Callout type="info">
  Gunakan dokumentasi ini sebagai panduan penggunaan. Detail implementasi API
  dan skema spreadsheet berada di bagian Referensi.
</Callout>

## Peta kerja MyCheck

1. **Akun dan cabang**: admin memastikan pengguna aktif dan akses cabangnya benar.
2. **Template shift**: admin menyusun SOP, kategori, checklist point, dan field handover.
3. **Pelaksanaan**: PJ membuka shift, petugas bergabung, lalu mengerjakan checklist.
4. **Perlindungan progress**: draft tersimpan di perangkat dan sheet `Drafts`.
5. **Penutupan**: PJ mengisi handover, menyelesaikan validasi, dan menutup shift.
6. **Pelaporan**: tim meninjau laporan, membagikan tautan bila diperlukan, dan memakai addendum untuk koreksi setelah penutupan.

## Istilah penting

- **Definisi shift**: template operasional yang berisi kategori SOP dan field handover.
- **Instance shift**: pelaksanaan definisi shift pada tanggal dan cabang tertentu.
- **PJ**: pengguna yang membuka shift dan berwenang menutupnya.
- **Draft**: input yang belum dikirim menjadi entry final.
- **Handover**: informasi yang diteruskan ke shift berikutnya.
- **Arsip**: salinan data tahunan yang dibuat admin tanpa menghapus data kerja aktif.
